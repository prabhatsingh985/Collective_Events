# Collective_Events (COLLECTR)

A collectibles platform frontend UI prototype specializing in **Hot Wheels** and **Trading Cards**.

---

## 🌟 Overview

**COLLECTR** is engineered for physical asset collectors, featuring:
- **Hot Wheels**: Super Treasure Hunts (STH), Red Line Club (RLC) Exclusives, Original 1968 Sweet 16 Redlines, Car Culture series, and Chases.
- **Trading Cards**: Graded slabs (PSA 10 Gem Mint, BGS 9.5), 1st Edition Pokémon Grails, Fleer Michael Jordan rookies, and Magic: The Gathering Alpha Black Lotus.

---

## ✨ Features

- **Landing Page**: 3D tilted preview showcase, Featured categories, Trending market gainers, and platform statistics.
- **Explore Catalog**: Instant search across names, series, and tags with faceted filters for brand, year, rarity tier, condition, and price slider.
- **Hot Wheels Discovery Hub**: Dedicated garage aesthetic, series selector chips, and rare finds spotlight.
- **Trading Cards Discovery Hub**: Prismatic holographic cards, PSA/BGS grading slab aesthetics, and popular set filters.
- **My Collection Dashboard**: Live portfolio valuation, Hot Wheels vs Trading Cards breakdown bar, 6-month aggregate value sparkline, and active wishlist tracking.
- **Collectible Detail View**: High-res multi-angle gallery, historical price charts, technical specifications, and 1-click collection/wishlist toggling.
- **Interactive UI**: Micro-interactions, holographic foil card sheen, celebratory confetti, and glass toast notifications.

---

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vite.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animation / FX**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **State**: React Context + `localStorage` persistence

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Dev Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 3. Build for Production
```bash
npm run build
```
